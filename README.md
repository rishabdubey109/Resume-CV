# Personal Resume Website

A clean and responsive personal CV/resume website developed using HTML, CSS and JavaScript.

## Features

- Responsive design
- Career objective
- Education details
- Technical and soft skills
- Projects
- Experience
- Languages
- References
- Contact section
- JavaScript form validation
- Mobile navigation
- Back to top button

## Technologies Used

- HTML5
- CSS3
- JavaScript
